Cat Energy — Responsive Website

Cat Energy is a responsive website for a healthy nutrition brand. The project was developed as part of the HTML Academy professional frontend development course.

The website is built with HTML, SCSS and JavaScript, following the provided design and technical requirements.

Features

- Responsive layout for desktop, tablet and mobile devices.
- BEM methodology for organizing CSS classes.
- SCSS for maintainable and structured styles.
- Gulp for development workflow automation.
- Mobile navigation menu.
- Interactive form elements.
- Interactive UI components implemented with JavaScript.

Tech Stack

- HTML5
- CSS3
- SCSS
- JavaScript
- Gulp
- BEM
- Git

Getting Started

To run the project locally:

1. Clone the repository:
   
   git clone https://github.com/AndeyAK/Cat-energy.git

2. Navigate to the project directory:
   
   cd Cat-energy

3. Install dependencies:
   
   npm install

4. Start the development workflow:
   
   npm start

Check the "package.json" file for available scripts.
